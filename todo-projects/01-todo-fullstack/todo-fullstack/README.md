# Spring Boot + Vite React Todo

Full-stack Todo application demonstrating:

- Spring Boot REST API
- Spring Data JPA
- H2 database
- DTO + Service + Repository layers
- Validation + global exception handling
- React + Vite
- Axios
- TanStack Query (`useQuery`, `useMutation`, query invalidation)

## Start backend

```bash
cd backend
mvn spring-boot:run
```

## Start frontend

Open another terminal:

```bash
cd frontend
npm install
npm run dev
```

Open http://localhost:5173
