# Revision Dashboard

HTML + Alpine.js + Tailwind CSS revision tracker for Java / Spring Boot / Microservices / System Design / AWS.

## Run

No build is required.

Simply open:

```text
index.html
```

in a browser.

## Features

- Topic roadmap
- Search
- Category filter
- Status filter
- Difficulty filter
- Completion tracking
- Progress percentage
- Important/starred topics
- Per-topic notes
- Dark mode
- LocalStorage persistence
- Responsive Tailwind UI

## Tech

- HTML5
- Alpine.js 3
- Tailwind CSS CDN
- Browser LocalStorage

## Roadmap Included

- Core Java
- Spring
- Spring Boot
