# Java Interview Utilities

Maven project containing interview-focused Java utilities.

## Anagram approaches
- `SortingAnagramChecker` — O(n log n)
- `HashMapAnagramChecker` — O(n) average
- `FrequencyArrayAnagramChecker` — O(n), O(1) fixed ASCII space

## Additional utilities
- Palindrome
- String reverse
- Character frequency
- First non-repeating character
- Duplicate characters
- Two Sum
- Second largest
- Missing number (XOR)
- Array rotation
- Prime checker
- Factorial
- Fibonacci
- Armstrong number
- Palindrome number

`UtilitiesDemo` demonstrates the implementations.

## Run
```bash
mvn clean compile
java -cp target/classes com.prem.anagram.UtilitiesDemo
```
