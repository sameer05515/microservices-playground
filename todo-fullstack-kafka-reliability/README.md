# Todo Fullstack — Observability & Integration Testing Layer

Spring Boot + MySQL + Redis + JWT/Refresh Token + RBAC + JPA Specifications + React/Vite + TanStack Query.

## New layer in this version

### Proper integration testing
- Testcontainers MySQL 8.4
- Testcontainers Redis 7
- Spring Boot `@SpringBootTest`
- `MockMvc` end-to-end API tests
- Flyway migrations execute against a real MySQL container
- JWT authentication is exercised in integration tests
- Redis cache path is exercised by repeated Todo reads

Run:
```bash
cd backend
mvn test
```
Docker must be available because Testcontainers starts real containers during tests.

### Structured logging
The backend writes JSON logs with:
- timestamp
- level
- logger
- thread
- message
- correlationId
- requestId

### Correlation / Request ID
Every HTTP request gets:
- `X-Correlation-ID`: client-supplied value is accepted and sanitized, otherwise generated
- `X-Request-ID`: always generated by the API

Both IDs are returned in response headers and included in structured logs.

### Metrics
Spring Boot Actuator + Micrometer Prometheus registry expose:
- HTTP request metrics
- JVM/process/system metrics
- Todo Redis cache hit/miss counters
- Redis lock contention counter
- distributed rate-limit rejection counter

Prometheus endpoint:
`/actuator/prometheus`

### Prometheus + Grafana
Root Docker Compose starts:
- MySQL: `localhost:3306`
- Redis: `localhost:6379`
- API: `localhost:8080`
- Prometheus: `localhost:9090`
- Grafana: `localhost:3000`

Grafana is provisioned automatically with a Prometheus datasource and a Todo API dashboard.

## Full Docker run
Build backend first:
```bash
cd backend
mvn clean package -DskipTests
cd ..
docker compose up --build
```

Then:
- API: http://localhost:8080
- Swagger: http://localhost:8080/swagger-ui.html
- Health: http://localhost:8080/actuator/health
- Prometheus: http://localhost:9090
- Grafana: http://localhost:3000

Grafana default login is normally `admin/admin`; change it for any real environment.
