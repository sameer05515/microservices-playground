# Mini Gmail v2

Node.js + Express + EJS + JSON storage.

## Features
- Login / Registration
- Inbox / Sent
- Compose
- Save Drafts
- Star / Unstar
- Trash / Restore / Permanent Delete
- Reply / Forward
- Search
- Unread count
- Gmail-like responsive UI

## Run
npm install
npm run dev

Open http://localhost:3000
