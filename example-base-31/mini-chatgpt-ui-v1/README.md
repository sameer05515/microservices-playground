# Mini ChatGPT UI V1

React + Vite ChatGPT-style UI.

## Requirements

- Node.js 18+
- npm

## Run

```bash
npm install
npm run dev
```

Open:

```text
http://localhost:5173
```

## Production build

```bash
npm run build
npm run preview
```

## V1 Features

- ChatGPT-style sidebar
- New Chat
- Recent conversations
- Responsive UI
- Message composer
- Enter to send
- Shift+Enter for newline
- Mock assistant response
- Typing indicator
- Starter prompts

No backend or API key is required.
