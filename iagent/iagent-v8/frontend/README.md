# iAgent Frontend V7

React + Vite UI for iAgent V7.

## Run

```bash
npm install
npm run dev
```

Frontend:

```text
http://localhost:5173
```

Backend:

```text
http://localhost:8080
```

## V7 UI

- Upload JAR
- Browse uploaded JARs
- Browse public classes and methods
- Configure JavaServices
- Test JavaServices
- View execution history and request/response logs
- Learn how to invoke dynamic endpoints
