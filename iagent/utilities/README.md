# Maven Java Blank Project

A minimal Maven Java project with empty source directories.

## Structure

```text
maven-java-blank-src/
├── pom.xml
└── src/
    ├── main/
    │   ├── java/
    │   └── resources/
    └── test/
        ├── java/
        └── resources/
```

No Java source files or test classes are included.

## Build

```bash
mvn clean package
```

## Compile

```bash
mvn clean compile
```
