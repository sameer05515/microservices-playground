# Node.js Arithmetic Operations

A simple JavaScript/Node.js project demonstrating common arithmetic operations.

## Requirements

- Node.js 18+ recommended
- npm

## Project Structure

```text
node-arithmetic-project/
├── package.json
├── README.md
├── src/
│   ├── arithmetic.js
│   └── index.js
└── test/
    └── arithmetic.test.js
```

## Operations

- Addition
- Subtraction
- Multiplication
- Division
- Modulus
- Power
- Increment
- Decrement

## Run

```bash
npm start
```

Expected output:

```text
Arithmetic Operations
=====================
20 + 6 = 26
20 - 6 = 14
20 * 6 = 120
20 / 6 = 3.3333333333333335
20 % 6 = 2
20 ^ 6 = 64000000
20 + 1 = 21
20 - 1 = 19
```

## Run Tests

```bash
npm test
```

No external npm dependencies are required.
